
              Hipparchus 4.1 RELEASE NOTES

The Hipparchus team is pleased to announce the release of hipparchus-4.1

The Hipparchus library is a library of mathematical components. It started as a fork of Apache Commons Math.

This is a minor release, adding Lebedev integrator, roman numerals, complex Schur transformer,
trilinear interpolation, random generators for exponential, gamma and Nakagami distributions,
half Cauchy, half normal and inverse gamma distributions, RANSAC algorithm,
revamped constrained optimizers, and numerous small improvements and bug fixes.

Changes in this version include:

New features:
o issues/469:  Added support for roman numerals. 
o issues/446:  Add convergence checker provider for Fielded scalar. 
o issues/442:  Added Complex Schur transformer 
o issues/437:  Added trilinear interpolation 
o issues/439:  Added Field.isSmall to help convergence checks in Field iterative algorithms. 
o issues/355:  Added evaluation of bicubic and tricubic interpolation functions with CalculusFieldElement 
o issues/428:  Added half and twice on CalculusFieldElement. 
o issues/424:  Added RANSAC algorithm for estimating the parameters of a mathematical model. 
o issues/421:  Added random generators for exponential, gamma and Nakagami distributions. 
o issues/419:  Added half Cauchy, half normal and inverse gamma distributions. Thanks to Xavier Vasseur. 
o issues/406:  Added AxisChecker helper class to check grid data consistency. 
o issues/400:  Add getNorm2Sq in geometry. 
o issues/386:  Add getNorm2 for Vector. 

Fixed Bugs:
o issues/488:  Restored Vector.getNormSq() as a default method, and FieldVector2D.getNormSq() and
               FieldVector3D.getNormSq(), removed without prior deprecation. They are now deprecated
               in favor of getNorm2Sq() and will be removed in 5.0. 
o issues/488:  Restored SQPOptimizerS, SQPOptimizerGM, AbstractSQPOptimizer and SQPOption getConvCriteria,
               setConvCriteria and DEFAULT_CONV_CRITERIA, removed without prior deprecation. They are now
               deprecated and will be removed in 5.0. The restored optimizers keep their 4.0.3 default settings. 
o issues/488:  Restored ADMMQPOption.DEFAULT_SCALING to true, its 4.0.3 value. 
o              Fixed ADMMQPModifiedRuizEquilibrium scaling limits: scaling factors below the minimum,
               non-positive or not finite were not reset to 1. 
o issues/488:  Use the magnitude of the value instead of norm() in the convergence and size checks of Carlson and
               Legendre elliptic integrals, whose results depended on the derivatives carried by the arguments,
               and for consistency in Jacobi theta functions. 
o issues/488:  Time checks of field integrators (integration span and last step detection) now compare time values
               only, ignoring the derivatives carried by the time. Too small intervals were not detected and an
               extra step could be taken. 
o issues/488:  Fixed-step Runge-Kutta integrators no longer call the overridable getDefaultStep() from their constructor. 
o issues/486:  Fixed indices problems with the GraalVM native image and Window operating system combo. 
o issues/481:  Fixed continuous integration failures by improving test coverage of new code. 
o issues/471:  Fixed overflow in MathArrays.distance1. Thanks to ser10us. 
o issues/470:  Fixed overflow in MultidimensionalCounter. Thanks to ser10us. 
o issues/465:  Fixed overflow in DfpMath.pow and DfpMath.splitPow. Thanks to AviranAbady. 
o issues/459:  Forbid all grouping (including commas) in ComplexFormat. Thanks to yin-mao. 
o issues/457:  Implement in FastMath methods introduced in Math as of Java 25. Thanks to Hanbing59. 
o issues/394:  Prevent stack overflow in digamma function. 

Changes:
o              Changed SQPOption defaults: DEFAULT_EPSILON from 1.0e-9 to 1.0e-7, DEFAULT_MU from 0.1 to 1.0e-4
               and DEFAULT_MAX_LINE_SEARCH_ITERATION from 20 to 30. They apply to SQPOptimizerS2 and to any
               SQPOption built by user code, including one passed to the deprecated SQP optimizers. 
o              getCurrentSignedStepsize() of fixed-step Runge-Kutta integrators now returns the configured step
               before integration starts, instead of NaN. 
o issues/462:  Replaced double[] arrays with Fittable interface in RANSAC fitting classes. 
o issues/460:  Allow small numerical tolerance in SmoothStepFactory.checkBetweenZeroAndOneIncluded 
o              Add some FunctionalInterface tag. 
o issues/413:  Reverted the FastMath reduction changes 
o issues/430:  Update UnivariateDifferentiableSolver with UnivariateDerivative1. 
o issues/398:  Implement non-trivial norm for CalculusField inheritors. Note that norm() of derivative types and
               tuples now includes all components, for example Gradient(0.5; 100, -200).norm() is 300.5 instead of 0.5.
