
              Hipparchus 5.0 RELEASE NOTES

The Hipparchus team is pleased to announce the release of hipparchus-5.0

The Hipparchus library is a library of mathematical components. It started as a fork of Apache Commons Math.

5.0 is a major release.

IMPORTANT NOTE: This version now requires Java 21

Changes in this version include:

New features:
o issues/497:  Added DataPoint interface and replaced Clusterable and Fittable interfaces. 

Fixed Bugs:
o issues/521:  Fixed log normal distribution inverse CDF. Thanks to ajrilatt. 
o issues/516:  Removed deprecated classes and methods in geometry and optimizers. 
o issues/513:  Fixed Complex isFinite method. Thanks to Axel Kramer. 
o issues/507:  Fixed wrong advertised order of Adams-Moulton integrator (double and Field versions). Thanks to rcgiri-physics. 
o issues/505:  Added Software Build Of Materials generation. 
o issues/502:  Fixed Wilcoxon signed rank test whenever the positive and negative rank sums are equal. Thanks to Tasuku Kobayashi. 
o issues/341:  Fixed documentation. Thanks to mmatsn. 

Changes:
o issues/516:  Removed deprecated AbstractUnivariateDifferentiableSolver.computeObjectiveValueAndDerivative(double),
               replaced by computeObjectiveValueAndDerivative1(double). 
o issues/516:  Removed deprecated SQPOption.getConvCriteria, setConvCriteria and DEFAULT_CONV_CRITERIA. 
o issues/516:  Removed SQPOption qpMaxLoop and useFunHessian settings (getters, setters and default constants),
               which were used only by the removed SQPOptimizerS and SQPOptimizerGM. 
o issues/516:  Changed ADMMQPOption.DEFAULT_SCALING from true to false. 
o issues/497:  Moved DistanceMeasure from clustering module to core module. 
o issues/497:  Added compute(DataPoint, DataPoint) to DistanceMeasure.
